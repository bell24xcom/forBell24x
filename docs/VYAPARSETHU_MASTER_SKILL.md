## COMPETITION POSITIONING

**Do NOT compete with:** IndiaMART, TradeIndia, ExportersIndia, Justdial.
These are directories. We compete on Google search but lose if we position there.

**Real category:** SAP Ariba, Coupa, Thomasnet, Alibaba Trade Assurance, Razorpay-style infrastructure.

**Differentiator:** AI-native MSME procurement infrastructure stitching discovery + verification + protected payment + trust scoring — which no one in India has done.

**Valuation logic:** Directory plays = 5-8x revenue. Infrastructure plays = 20-40x. The category we choose determines the multiple.

3. Does this make trade Faster?

**If only 1 YES → defer.**
